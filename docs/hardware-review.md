# 原理图核对记录

依据：`SCH_Schematic8_2026-09-27.pdf`（单页，标题栏 V1.0）、`BOM_DRV8874_Schematic8_2026-09-27.xlsx`、`Gerber_PCB8_2026-09-27.zip`。已核对 PDF、BOM、Gerber 预览及包内飞针测试网络数据，未完成铜层电气连通性验证，也未检查实物。

## 已确认的连接

- U1 为 A 路，U3 为 B 路；型号均为 DRV8874PWPR。
- EN/IN1 分别连接 PWM_A、PWM_B，PH/IN2 分别连接 DIR_A、DIR_B。
- 两路 PMODE、IMODE 均接地；GND、PGND、EP 均连接 GND。
- nSLEEP 经 10 kΩ 上拉至 +3.3V；nFAULT 为明确的未连接标记。
- IPROPI 各接 1.8 kΩ 到 GND，未引出 ADC；VREF 各采用 2.7 kΩ/10 kΩ 分压。
- A 路 C14、B 路 C7 为 22 nF，跨接 CPH/CPL。
- A 路 C6、B 路 C12 为 100 nF，跨接 VCP/VM；连接拓扑与 TI 推荐相符。
- A 路 C1/C2/C3、B 路 C9/C10/C11 均连接 VM/GND，标值分别为 10 µF、100 nF、22 µF。
- C13 为 VM/GND 间的 1000 µF 极性电容，正端接 VM。
- C5、C4 分别为 A、B 编码器电源的 100 nF 去耦。
- 四个安装孔 SCREW1～SCREW4 在图中连接 GND。
- P2 的 1/3 脚为 +3.3V，2/4 脚为 GND；其余接口编号详见 README。

## 当前接口的功能边界

| 电路配置 | 使用影响 |
| --- | --- |
| 板上没有 3.3 V 稳压器 | 主控接口需提供外部 3.3 V，且承担编码器供电 |
| PMODE 接地 | 使用 PWM + DIR；PWM=0 为刹车 |
| nSLEEP 只做上拉 | 主控无法通过当前接口独立让驱动进入休眠/高阻态 |
| nFAULT 未连接 | 主控无法从接口读取驱动故障状态 |
| IPROPI 未引出 | 内部限流可用，主控电流采样接口未提供 |
| 编码器信号直接透传 | 需核对编码器供电、电平及上拉需求 |
| 约 3.2 A 限流设置 | 是否适合目标电机，需结合启动、堵转电流及负载测试判断 |

这些配置是否需要修改，取决于模块希望提供的功能。若计划增加电流闭环、故障诊断或独立滑行控制，应在后续硬件版本中增加对应信号接口。

## BOM 和 Gerber 的补充结果

- BOM 包含 13 组物料、31 个位号（含 4 个安装孔）；BOM 与飞针文件中的同名器件均能对应。飞针文件另含独立 PAD 项，未作为新增采购器件计数。
- 阻值和容值与 PDF 中对应位号一致。BOM 指定电阻为 0402；10 µF/100 nF 电容为 0603；22 µF 为 1206；22 nF 为 0402。
- C13 型号 PA35V1000M10x15、LCSC 料号 C46550434，规格为 1000 µF/35 V。其余电容没有采购料号或耐压信息。C13 耐压依据：[供应商规格页](https://jlcpcb.com/partdetail/jieerrui-PA35V1000M10x15/C46550434)。
- 电机连接器 U2/U5 为 ZX-XH2.54-6PWZ（C7429645），封装名中的间距为 2.50 mm；需按配套件图纸确认。
- Gerber 板框中心线范围 X=25.400～64.135 mm、Y=-56.388～-18.415 mm，尺寸约 38.735 × 37.973 mm，四角圆角约 R1 mm。四个安装孔的钻孔直径约 3.2004 mm。
- 包内包含顶/底铜、顶/底阻焊、顶/底丝印、顶层钢网、板框与镀通孔钻孔。器件坐标记录中物料均在顶面，未提供底层钢网。
- 已核对飞针数据中 P2、U2/U5、CN2、C13 与两颗驱动的 PWM/DIR、PMODE、IMODE、VM、GND、EP 网络标注，与 PDF 对应。网络标签对应不能代替铜层实际连通性检查。
- 两颗驱动的 EP 区域各可见 4 个约 0.3048 mm 的散热过孔；底层有铜区和周边过孔。实际散热能力仍需结合板厚、铜厚与带载温升测试。
- 顶层丝印标注 VM:12V-26.8V，供电声明应围绕该设计目标验证。顶面未见清晰的 P2 信号表或电机接口电源/编码器标签，建议后续版本增加标识，帮助接线。

## PCB 与实物尚待确认

1. VM 侧陶瓷电容的额定耐压与有效容量；C13 的纹波电流和温升裕量；电荷泵电容的介质和耐压。
2. 六针电机连接器的具体型号、封装方向、端子载流能力与线束顺序。
3. VM、OUT1、OUT2、PGND 的铜厚、走线/铺铜及大电流回路。
4. EP 焊盘焊接、接地铜面积、散热过孔；两路同时工作时的热耦合。
5. 去耦与电荷泵电容到芯片的实际距离和回路面积，编码器信号是否受到功率回路干扰。
6. 电源输入反接和瞬态管理需求；图中未画出反接保护、TVS 或保险丝。
7. 单路及双路连续带载的温升、限流表现、快速减速时 VM 电压变化。

仅凭当前原理图，无法给出模块的持续电流额定值或确认 PCB 是否能满足目标负载。
